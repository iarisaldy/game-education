# 🎈 Dunia Main & Belajar Balita 👶✨

**Dunia Main & Belajar Balita** adalah aplikasi game edukasi web interaktif, ceria, dan aman yang dirancang khusus untuk anak-anak balita (usia 2+ tahun). Dibuat dengan antarmuka yang ramah anak, warna-warna menarik, efek suara interaktif, serta animasi yang menyenangkan.

> 💖 **Lisensi Ayah Tercinta**: Irfan Arisaldy

---

## 🚀 Fitur Utama & Permainan

Aplikasi ini memiliki 5 mode permainan edukatif yang dirancang untuk mengasah motorik halus, pengenalan visual, pendengaran, dan pemahaman logika dasar balita:

1. 🟡 **Bentuk & Warna**
   - Belajar mengenal bentuk dasar (Lingkaran, Persegi, Bintang, Segitiga) dan warna.
   - Permainan sortir drag & drop / ketuk yang mudah dan menyenangkan.

2. 🐱 **Dunia Hewan & Kuis Suara**
   - Mengenal berbagai hewan lucu beserta suara khasnya.
   - Mode kuis interaktif: Dengarkan suara hewan dan tebak hewan yang tepat!

3. 🫧 **Pop Gelembung Interaktif**
   - Bermain memecahkan gelembung angka (1-5) dan buah-buahan yang melayang.
   - Dilengkapi papan skor bintang ⭐️ untuk memberikan apresiasi positif kepada balita.

4. 🚜 **Mengenal Alat Berat**
   - **Mode Kenali**: Belajar nama dan fungsi alat berat (Excavator, Bulldozer, Dump Truck, Crane, dll.).
   - **Mode Tebak-tebakan**: Menguji ingatan dan pengenalan balita dengan petunjuk suara & aksi.

5. 🚒 **Dunia Mobil-mobilan & Sirine**
   - **Garasi Interaktif**: Menyalakan sirine, membunyikan klakson, dan menggerakkan mobil pemadam, ambulans, polisi, serta mobil balap.
   - **Mode Tebak Mobil**: Mengasah kemampuan anak mendengarkan suara sirine dan menebak jenis kendaraannya.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik & aksesibel.
- **CSS3 (Vanilla CSS)**: Design system kustom dengan warna-warna pastel ceria, animasi halus, glassmorphism, dan tampilan responsif (mobile & desktop).
- **JavaScript (ES6+)**: Logika interaksi game, efek audio, animasi gelembung, serta sistem kuis interaktif.
- **Google Fonts**: Font *Fredoka* & *Quicksand* yang ramah anak dan mudah dibaca.

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/iarisaldy/game-education.git
   ```

2. **Masuk ke direktori proyek**:
   ```bash
   cd game-education
   ```

3. **Buka file `index.html`** langsung di browser pilihan Anda (Google Chrome, Firefox, Safari, Edge), atau gunakan ekstensi *Live Server* di VS Code.
